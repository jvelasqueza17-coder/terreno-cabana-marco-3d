# 🏡 Visor 3D Interactivo - Terreno & Cabaña Marco

Modelo tridimensional interactivo para visualización web accesible desde cualquier computador o dispositivo móvil sin necesidad de instalar software adicional.

🌐 **Enlace directo al visor:** [https://jvelasqueza17-coder.github.io/terreno-cabana-marco-3d/](https://jvelasqueza17-coder.github.io/terreno-cabana-marco-3d/)

---

### 🎮 Controles de navegación
- **Rotar 360°:** Clic izquierdo (PC) o arrastrar con 1 dedo (Móvil).
- **Zoom:** Rueda del mouse (PC) o gesto de pellizco (Móvil).
- **Desplazar (Pan):** Clic derecho (PC) o arrastrar con 2 dedos (Móvil).

### 🛠️ Herramientas incluidas
- **Vistas predefinidas:** Isométrica, Planta / Superior, Frontal, Lateral y Cabaña.
- **Ambientes de luz:** Modo Día, Atardecer, Noche y Estudio.
- **Modos visuales:** Estructura alámbrica (Wireframe) y rotación automática 360°.
- **Herramientas:** Captura de pantalla PNG en alta resolución y pantalla completa.
